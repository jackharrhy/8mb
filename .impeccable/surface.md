# Editor
Mode: Operate. Code-first.
First viewport: a single toolbar with Edit / Advanced navigation and Open video. No brand or page title. Desktop uses a large preview plus a 280px export column, then waveform and trim controls below the preview. Mobile stacks the export controls after the timeline.
Signature interaction: the selected waveform region, synchronized playhead, and draggable crop rectangle describe precisely the local clip being exported. All drag actions have numeric alternatives.
Empty state teaches choosing a file and privacy. Loading, error, encoding, cancelled and downloadable output states are explicit. Advanced commands expose progress, logs, saved local favorites and a playable output.
