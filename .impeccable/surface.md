# Editor
Mode: Operate. Code-first.
First viewport: 8mb brand, Edit / Advanced navigation, offline availability. A heading and local file action. Desktop uses a large preview plus a 280px export column, then waveform and trim controls below the preview. Mobile stacks the export controls after the timeline.
Signature interaction: the selected waveform region and draggable crop rectangle describe precisely the local clip being exported. All drag actions have numeric alternatives.
Empty state teaches choosing a file and privacy. Loading, error, encoding, cancelled and downloadable output states are explicit. Advanced commands expose progress, logs, saved local favorites and a playable output.
